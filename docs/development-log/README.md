# DSH 生态开发日志

> dsh-deep-whale 仓库的开发日志索引（DSH 生态：皮肤、插件、双会话协作等）。
> 记录对象：本仓库内 maid-atelier / session-bridge 等插件的完成事实、产品决策与验证结果。
> 与 code 项目的 workbar 开发日志（code/docs/development-log/）相互独立，不重复登记。

## 写入规则

- 新日志按本地日期写入 `YYYY-MM-DD.md`（当天文件不存在时新建）。
- 每条使用 `## YYYY-MM-DD HH:mm · 协作方` 标题并按时间倒序排列。
- 只记录已经完成且有事实依据的内容；未完成事项记录在对应插件 README/TODO 或 code 项目 TODO。
- 每次新增日期文件或改变当日主题时，同步更新下方索引。
